# α6400 Creative Style model/cursor boundary plan

## Goal

Determine how far the α6400 2.00 generic setting-node helper proves the path from
selected menu items toward a model value, without promoting a helper name or an
unresolved indirect/local call into a Creative Style commit, renderer, event,
touch, or persistence claim.

## Static sources

- exact `lib/viewUnified2.so`, size `11,530,552`, SHA-256
  `1e2867b6bff2d4fd4d3b93bacf8c7da0b9a86f266b4ba1763230e33badb6e7f2`;
- the prior Creative Style menu-list, registry-consumer, and selected-state
  reports, used only as independent provenance boundaries.

No camera access, Sony camera-binary execution, device/USB writes, firmware
packaging, or installable output is permitted.

## Tasks

1. Add fail-closed tests for the exact `CmnSettingNodeUtil` method identities,
   object-field reads/writes, direct calls, and bounded virtual interface calls.
2. Implement a contract that distinguishes generic cursor/selection evidence
   from the still-unresolved model terminal and Creative Style binding.
3. Implement a read-only exporter that derives the bounded facts from ELF
   symbols/relocations and Thumb control flow while pinning source identity and
   verifying that the input does not change.
4. Emit a reviewed report and update the Creative Style deep dive with both the
   positive generic helper surface and all negative boundaries.
5. Run focused, full-analysis, and safe verification before committing only the
   scoped files.

## Acceptance boundary

The slice may claim generic in-memory cursor/selection control, named process-ID
and process-value-ID lookup, and existence of a method named `setValueToModel`.
It must keep Creative Style-specific binding, the final model setter/commit,
menu-event publication, renderer consumption, touch routing, durable
persistence, Creative Look equivalence, and runtime behavior false unless exact
new address- and identity-pinned evidence proves them.
