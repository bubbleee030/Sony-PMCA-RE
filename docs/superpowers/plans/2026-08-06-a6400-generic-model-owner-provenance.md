# α6400 generic model-owner provenance plan

## Goal

Trace the anonymous owners behind the verified generic cursor/model sequences to
their inbound dispatchers and utility-member lifecycle, while keeping same-field
offsets, `.data.rel.ro` table address-taking, and module co-containment separate
from a typed Creative Style class binding.

The analysis is read-only and offline. No camera access, Sony camera-binary
execution, device writes, firmware packaging, or installable output is allowed.

## Tasks

1. Add fail-closed tests for exact VU4 table-dispatch targets, selector cases,
   receiver preservation, utility-member offsets, and address-taken metadata.
2. Represent the second VU4 EXIDX interval as two entries separated by a return,
   rather than promoting the entire interval into one function.
3. Prove VU7's shared `CmnSettingNodeUtil` receiver field and bound canonical
   direct prefixes, relocation-backed references, and mapped-pointer references
   into the anonymous target and its table-dispatch predecessor. Record partial
   canonical decoding as non-exhaustive rather than promoting negative evidence.
4. Bound the VU7 initializer candidate that allocates and stores a utility at
   the same field offset, while keeping its origin link to the target false.
5. Recheck all Creative Style root publications for exact absence from these
   dispatchers/targets and emit a reviewed report.
6. Run focused, real-export, full-analysis, and safety verification before a
   scoped commit.

## Acceptance boundary

Generic ViewBase/ViewBaseProduct-family dispatch and utility-member lifecycle
may be claimed only from exact transfers, relocations, and field provenance.
The concrete derived class, constructor-to-target identity, Creative Style
ownership, final model commit, persistence, renderer, touch, and Creative Look
remain false unless a typed or path-sensitive edge proves them.

The completed VU7 check found one exact `TBH` case predecessor rather than the
initial zero-inbound hypothesis. Its case path preserves entry `r0`, but the
address-taken owner remains anonymous and the same `+0x14c` initializer field
does not establish class identity.
