# α6400 Creative Style view/model binding plan

## Goal

Prove whether the target-native `ViewCreativeStyle` controller reaches an exact
Creative Style process-data type, value-read path, value-write path, backup
boundary, and model request without promoting that evidence to Creative Look,
touch-menu, renderer, or installable-firmware support.

## Static source

- exact `lib/viewUnified2.so`, size `11,530,552`, SHA-256
  `1e2867b6bff2d4fd4d3b93bacf8c7da0b9a86f266b4ba1763230e33badb6e7f2`.

The work remains offline and read-only. It must not access a camera, execute a
Sony camera binary, write a device or USB partition, package or flash firmware,
or emit proprietary bytes, disassembly, or key material.

## Tasks

1. Pin `ViewCreativeStyle` RTTI, its 94-slot primary vtable, its secondary
   address point, factory-style entry, constructor vptr stores, and object size.
2. Pin the slot-54 model/event initialization and the 20-case slot-64 controller
   dispatcher without naming unknown case semantics.
3. Follow the controller's process-data ID through the manager mapping table and
   bounded factory dispatcher into the exact
   `CmnViewProcessDataElementCustomCreativeStyle` RTTI/vtable.
4. Prove the manager's typed read overload boundary and five-argument value
   setter boundary.
5. Pin the setter's backup calls, five-parameter `@M00B` model request, and the
   separate controller-mode word/one-byte backup representation while keeping
   their semantics distinct.
6. Record the negative factory-registration and touch-route results, then emit a
   deterministic report and run real-export, analysis, safety, compilation,
   diff, and independent-review gates.

## Acceptance boundary

An exact typed process element, value setter, backup call, or model request may
be promoted only when every selector, table entry, vtable slot, relocation, and
call owner is bounded. The five integer arguments must not be labeled as
specific Creative Style fields until their individual semantics are proven.
The controller-mode word, whose backup helper serializes one byte, must not be
described as the selected Creative Style value. No result may claim Creative
Look equivalence, eight-axis support,
renderer/output binding, touch routing, installability, or camera-test
eligibility.

## Result

- `ViewCreativeStyle` is a concrete 94-slot screen/controller with exact model
  initialization and a 20-case event dispatcher.
- Dispatcher case 16 directly reaches the process-data ID-42 helpers, which map
  through the manager table and factory dispatcher to
  `CmnViewProcessDataElementCustomCreativeStyle`; exact getter slot 10 and
  setter slot 21 use the returned typed object.
- The typed write path reaches `setValue(int,int,int,int,int)`, whose bounded
  owner contains five backup-write call sites, five parameter-add call sites,
  and an `@M00B` operation-38 request call site; runtime path execution remains
  unproven.
- The separate `+0x15c` word is a resettable controller mode with a one-byte
  backup representation, not a proven selected-style field.
- Factory registration, five-argument semantics, eight-axis Creative Look,
  renderer/output sinks, touch routing, runtime behavior, and installability
  remain unproven.
